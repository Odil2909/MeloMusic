# Melo

Melo — прототип музыкального каталога на Next.js App Router. Главная получает с сервера реальные треки, альбомы и профили исполнителей из Jamendo; страницы альбомов и исполнителей открываются по ссылкам провайдера. Каталог используется только для некоммерческой технической проверки. Melo — временное рабочее название из [конфигурации бренда](src/config/brand.ts).

Поиск, пользовательские подборки и воспроизведение в Melo пока отключены. Jamendo API и лицензия каждой композиции не дают автоматического разрешения на коммерческий музыкальный сервис.

## Требования

- Node.js 20.9 или новее
- npm 10 или совместимая версия

## Установка и запуск

Установить зависимости из lock-файла:

```sh
npm ci
```

Запустить dev-сервер:

```sh
npm run dev
```

Откройте <http://localhost:3000>. Проверить API доступности можно по адресу <http://localhost:3000/api/health> или командой:

```sh
curl -i http://localhost:3000/api/health
```

Ожидаемый ответ: HTTP `200`, `Content-Type: application/json; charset=utf-8`, тело `{"status":"ok"}`.

## Проверки и production-запуск

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run start
```

`npm run start` запускает уже собранное приложение. Запускайте его после успешного `npm run build`.

## Переменные окружения

Для серверных маршрутов каталога нужен зарегистрированный Jamendo `JAMENDO_CLIENT_ID`. Скопируйте `.env.example` в `.env.local` и задайте переменную локально. `PORT` используется только отдельным проверочным скриптом этапа 1. Не публикуйте клиентский ID и не используйте публичный тестовый ID для приложения.

Чтобы передать переменные Node-скрипту прототипа, задайте их в текущей оболочке или запустите Node с `--env-file`:

```sh
node --env-file=.env.local scripts/verify-music-api.mjs "lofi"
```

Файл `.env.local` исключён из Git. Не добавляйте реальные секреты в исходники, README или другие документы. Инструкции по прототипу и ограничению коммерческого использования находятся в [docs/music-api-testing.md](docs/music-api-testing.md).

## Структура

```text
src/
  app/                 App Router, страница, глобальные стили и health route
  components/
    home/              состояния каталога и повторная загрузка
    layout/            оболочка приложения, навигация, шапка и отключённый плеер
    music/             карточки альбомов и артистов, строки треков
    player/            визуальные элементы управления плеером
    ui/                иконки, кнопки и изображения с fallback
  config/              временное название и настройки бренда
  features/home/       серверная загрузка главной и изолированные Stage 3 fixtures
public/
  images/              оригинальные локальные демонстрационные обложки
  icons/               локальные значки
docs/                  материалы исследования API этапа 1
scripts/               отдельный проверочный прототип этапа 1
```

## Статус этапов

- **Этап 1 — исследование API:** отчёт и инструкции сохранены в `docs/`; для коммерческого каталога провайдер пока не выбран. В `scripts/` оставлен изолированный тест Jamendo.
- **Этап 2 — основа приложения:** Next.js App Router, строгий TypeScript, Tailwind CSS, ESLint, metadata, health route и команды проекта.
- **Этап 3 — интерфейс:** тёмная дизайн-система Melo, адаптивный layout, локальные обложки, типизированный демо-каталог и интерфейсные состояния.
- **Этап 4 — серверная интеграция:** read-only адаптер Jamendo и внутренние API-маршруты; секрет остаётся на сервере.
- **Этап 5 — главная:** реальные ответы Jamendo, недавние альбомы с датами провайдера, артисты, жанры с доступными треками, fallback изображений, загрузка, ошибки и пустые состояния.
- **Позднее:** выбор лицензированного источника аудио, подключение Supabase, авторизация, настоящее воспроизведение, библиотека и пользовательские плейлисты — только в отдельных этапах.

Схема главной, live-проверки и ограничения разделов описаны в [отчёте этапа 5](docs/music-home-integration.md). Серверные маршруты и ограничения Jamendo описаны в [документе интеграции](docs/music-api-integration.md).

В проекте пока нет реального воспроизведения, регистрации, базы данных, пользовательских данных, платежей или сохранения избранного.
